================================================================================
 AllDefinedLogs.txt - 프로그램에서 사용하는 모든 로그 EVENT 명세
================================================================================
 로그 형식: [clock] NODE | EVENT | STATUS | message
 STATUS 종류: INFO / SUCCESS / FAIL / WARN (4가지만 사용)
================================================================================

EVENT: INIT
설명: 시스템 초기화 관련 이벤트 (System Clock 시작, KV 쌍 생성, Worker Thread 기동)
사용 노드: MASTER, WORKER1~4
STATUS 사용: INFO, SUCCESS, FAIL
예시:
  [      0.00] MASTER   | INIT      | INFO    | System Clock started at 0.00
  [      0.00] MASTER   | INIT      | SUCCESS | Generated 5000 KV pairs
  [      0.00] WORKER1  | INIT      | INFO    | Worker1 starting (P2P port 9101)
  [      1.00] WORKER1  | INIT      | SUCCESS | Received START signal. Beginning processing.

--------------------------------------------------------------------------------

EVENT: CONNECT
설명: 소켓 연결 관련 이벤트 (Master-Worker TCP 연결, 피어 목록 수신)
사용 노드: MASTER, WORKER1~4
STATUS 사용: SUCCESS, FAIL, INFO
예시:
  [      1.00] MASTER   | CONNECT   | SUCCESS | Worker1 connected from 1.2.3.4:50001
  [      0.00] WORKER1  | CONNECT   | SUCCESS | Connected to Master at 54.180.x.x:9000
  [      1.00] WORKER1  | CONNECT   | INFO    | Received peer list: 3 peers

--------------------------------------------------------------------------------

EVENT: DISTRIB
설명: Master의 작업 분배 결정 (어떤 작업을 어떤 Worker에 할당했는지)
사용 노드: MASTER
STATUS 사용: INFO
예시:
  [      2.00] MASTER   | DISTRIB   | INFO    | Task 0001 (key=a3f7) -> Worker1 (queue~1/10)
  [    500.00] MASTER   | DISTRIB   | INFO    | Progress: 1000/5000 completed

--------------------------------------------------------------------------------

EVENT: RESULT
설명: Master의 처리 결과 수신 (Worker로부터 SUCCESS/FAIL/REJECT 결과)
사용 노드: MASTER
STATUS 사용: SUCCESS, FAIL
예시:
  [      5.30] MASTER   | RESULT    | SUCCESS | Task 0001 SUCCESS by Worker1 (queue:3)
  [      7.80] MASTER   | RESULT    | FAIL    | Task 0003 FAIL by Worker2 -> Priority Queue

--------------------------------------------------------------------------------

EVENT: RECV
설명: Worker의 작업 수신 (Master로부터 새 작업을 받았을 때)
사용 노드: WORKER1~4
STATUS 사용: INFO
예시:
  [      2.00] WORKER1  | RECV      | INFO    | Task 0001 received (key=a3f7, queue:1/10)
  [     50.00] WORKER2  | RECV      | INFO    | Task 0088 received (key=00ff, queue:5/10) [RETRY #2]

--------------------------------------------------------------------------------

EVENT: PROC
설명: Worker의 작업 처리 결과 (가상 처리 후 성공/실패 판정)
사용 노드: WORKER1~4
STATUS 사용: SUCCESS, FAIL
예시:
  [      4.30] WORKER1  | PROC      | SUCCESS | Task 0001 SUCCESS (proc=2.30s, wait=0.50s)
  [      6.80] WORKER2  | PROC      | FAIL    | Task 0003 FAIL (proc=1.90s, wait=1.20s)

--------------------------------------------------------------------------------

EVENT: QUEUE
설명: Ready Queue 상태 변화 (70% 초과 경고, 포화 시 거부)
사용 노드: WORKER1~4
STATUS 사용: WARN, FAIL
예시:
  [     10.00] WORKER1  | QUEUE     | WARN    | Queue over 70%: 8/10 (after push)
  [     10.50] WORKER1  | QUEUE     | WARN    | Queue over 70%: 8/10 (after pop)
  [     12.00] WORKER3  | QUEUE     | FAIL    | Queue full (10/10). Task 0055 REJECTED

주의: WARN은 큐가 70% 초과 상태(8개 이상)에서 작업이 들어오거나 나갈 때마다 매번 기록.
      "전이 시 1회"가 아니라 해당 상태 유지 중 모든 push/pop 에서 발생.

--------------------------------------------------------------------------------

EVENT: LB
설명: P2P 부하 분산 (Worker 간 큐 조회, 작업 이전, ACK)
사용 노드: WORKER1~4, MASTER(P2P_MOVED 수신 시)
STATUS 사용: INFO, SUCCESS
예시:
  [    100.00] WORKER1  | LB        | INFO    | Expected wait 18.0s > 15.0s, querying peers...
  [    101.00] WORKER3  | LB        | INFO    | P2P query from Worker1, replied queue_size=3
  [    102.00] WORKER1  | LB        | INFO    | Transferring 2 task(s) to Worker3
  [    103.00] WORKER1  | LB        | SUCCESS | P2P transfer done: 2 to Worker3, 0 rejected
  [    103.00] MASTER   | LB        | INFO    | P2P: 2 task(s) Worker1 -> Worker3

--------------------------------------------------------------------------------

EVENT: STAT
설명: 최종 통계 출력 (필수 6개 지표 포함)
사용 노드: MASTER, WORKER1~4
STATUS 사용: INFO
예시:
  [   3200.00] MASTER   | STAT      | INFO    | [1] Total tasks processed    : 6250
  [   3200.00] MASTER   | STAT      | INFO    | [2] Total SUCCESS            : 5000
  (Worker별, Master 전체 통계 모두 포함)

지표 목록:
  [1] Worker별 작업 처리량 (건)
  [2] Worker별 성공/실패 횟수 (건)
  [3] 작업 평균 대기시간 (sec)
  [4] P2P 부하 분산 이벤트 횟수 (회)
  [5] 장애 재할당 횟수 (건)
  [6] 전체 수행시간 (sec, System Clock 최종값)

--------------------------------------------------------------------------------

EVENT: TERMINATE
설명: 정상 종료 (Master의 종료 신호 전송, Worker의 수신 및 종료)
사용 노드: MASTER, WORKER1~4
STATUS 사용: INFO, SUCCESS
예시:
  [   3200.00] MASTER   | TERMINATE | INFO    | Sent TERMINATE to all workers
  [   3201.00] WORKER1  | TERMINATE | INFO    | Received TERMINATE from Master
  [   3201.00] WORKER1  | TERMINATE | SUCCESS | Worker1 terminated gracefully.
  [   3205.00] MASTER   | TERMINATE | SUCCESS | All workers terminated. Master shutting down.
